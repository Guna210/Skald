# Text and audio defaults

Every default from `SPEC.md` C1, each with a one-line rationale. Tasks that implement a default update this file; changing or adding a default needs Orchestrator approval.

## C1.1 Import (EPUB)

1. **DRM-protected books are refused** (`META-INF/encryption.xml` listing anything other than font obfuscation → `epub_drm`, with a plain explanation; DRM is never removed). *Rationale: removing DRM is not something Skald does, and a clear message beats a broken import.*
2. **Reading order is the OPF spine**; `linear="no"` items are excluded unless the user includes them. Chapter titles come from the EPUB 3 navigation document, else the NCX, else the first heading, else "Chapter N". *Rationale: the spine is the author's intended order, and this chain finds the best available title.*
3. **Each spine item is a chapter**; a navigation entry pointing inside a file splits it at that anchor. *Rationale: matches how most EPUBs are built, and handles books that put several chapters in one file.*
4. **Suggested skips, unticked by default** (the user can re-tick): items marked by `epub:type` or landmarks as cover, toc, copyright-page or index, and items with fewer than 200 characters of text. *Rationale: these are rarely worth listening to, but the choice stays with the user.*
5. **Text extraction from XHTML:** block elements → paragraphs (`h1`–`h6` kept as their own heading paragraph); `<br>` → line break inside a paragraph (each line trimmed, empty lines dropped); images skipped (alt text not read by default); `script`/`style` skipped; tables read row by row (cells joined by one space); footnotes/endnotes (`epub:type="noteref"`/`"footnote"`/`"endnote"`, `role="doc-noteref"`/`"doc-footnote"`/`"doc-endnote"`) → note references removed (keeping tails), note bodies skipped by default; page-break markers (`epub:type="pagebreak"`, `role="doc-pagebreak"`) skipped; ruby annotations (`<rt>`, `<rp>`) skipped. *Rationale: gives clean narration text; notes interrupt listening, page numbers should not be read aloud, and ruby tags would duplicate base text.*
6. **Metadata read:** title, author(s), language (`dc:language`), cover image (EPUB 3 `cover-image` property or EPUB 2 `meta name="cover"`). *Rationale: needed for tags, language-specific text handling and cover art.*
7. **XML parsed with lxml without network access, DTD loading or entity resolution** (`resolve_entities=False`, `no_network=True`, `load_dtd=False`). *Rationale: untrusted books must not be able to read local files or call out.*

## C1.1 Import (TXT and Markdown)

1. **Encoding detection:** check BOMs in order UTF-32 LE/BE, UTF-16 LE/BE, UTF-8 (`guessed=False`); if no C0 bytes (`0x00`–`0x1F` other than `\t \n \r \f`) are present, run the 8-bit path (strict UTF-8 `guessed=False`, else `cp1252` or `latin-1` `guessed=True`); if only NULs are C0, run the NUL-cadence test (even length, `>= 30%` NULs in even/odd positions and `<= 5%` in the other -> strict `utf-16-be`/`utf-16-le`, `guessed=True`, else 8-bit path with NULs removed, `guessed=True`); if other C0 bytes are present, try NUL-cadence, else even-length strict `utf-16-le` then `utf-16-be` with no C0 characters (`guessed=True`; known limit: BOM-less BE CJK without NULs may decode as LE), else 8-bit path with C0 bytes removed (`guessed=True`). Normalize `\r\n` and `\r` to `\n`. *Rationale: avoids misclassifying stray NULs as UTF-16 and handles BOM-less Cyrillic/CJK UTF-16 without external detection libraries.*
2. **File limits:** reject files over 100 MB (`100_000_000` bytes), files with no non-whitespace text, and imports yielding zero chapters/paragraphs as `unsupported_format`. *Rationale: prevents unbounded memory use on huge inputs and catches empty or non-text files before project creation.*
3. **TXT paragraphs and chapter detection:** blank-line-separated blocks become paragraphs with internal single newlines joined by `" "` and whitespace collapsed; split chapters on blocks of at most 3 lines whose stripped first line matches `^(chapter|part|book)\b` (case-insensitive), is `<= 80` chars, and has at most 8 words, or single-line blocks (`<= 80` chars) preceded by 2+ blank lines; heading blocks emit a leading `is_heading=True` paragraph and title the chapter by their first line, while unheaded chapters are titled `"Chapter N"`. *Rationale: unwraps hard-wrapped Gutenberg prose cleanly and detects standard novel divisions without splitting wrapped prose lines.*
4. **Markdown structure and skipped elements:** parsed via `markdown-it-py` (CommonMark + `table`); `h1`/`h2` (ATX or setext) start chapters and emit a leading `is_heading=True` paragraph, `h3`–`h6` emit `is_heading=True` paragraphs, and paragraphs, list items, blockquote paragraphs, and table rows (cells joined by `" "`) emit one paragraph each; `text` and `code_inline` are kept, `softbreak` becomes `" "`, `hardbreak` and inline `<br>`/`<br/>`/`<br />` tags (case-insensitive) become `"\n"`, and emphasis/link markup are dropped keeping text; **images (alt text never read), `html_block`, non-`<br>` `html_inline` tokens (keeping text between inline tags), and fenced/indented code blocks are skipped**. *Rationale: uses a compliant CommonMark parser to avoid regex pitfalls, keeps `<br>` consistent with EPUB, and drops non-narration markup.*
5. **Book and chapter metadata:** `title` = file stem, `authors = []`, `language = None`; chapters have `linear = True`, suggested skip `"short"` below 200 characters (C1.1 rule 4 / D2), and `included = not suggested_skip`. *Rationale: aligns TXT/Markdown chapters with EPUB chapters while deferring language selection to import/UI.*

## C1.2 Text preparation

1. **Unicode NFC**; remove U+00AD (soft hyphen), U+200B (zero-width space), U+2060 (word joiner), and U+FEFF (zero-width no-break space / BOM); **keep U+200C (ZWNJ) and U+200D (ZWJ)** because they change spelling and pronunciation in Indic and Persian scripts (Kokoro supports Hindi) and join emoji sequences; collapse runs of Unicode whitespace without `"\n"` to one ASCII space (`" "`, including tabs, NBSP, U+2028, U+2029, and U+202F) and runs containing `"\n"` (including `"\r\n"`) to one `"\n"`, then strip the ends; keep quotation marks and dashes as written. *Rationale: one canonical form for stable hashing and chunking, preserving script-meaningful joiners and paragraph line breaks without altering what the author wrote.*
2. **Lexicon (per project):** `synthesis text = apply_lexicon(normalize(display_text), rules)`, leaving `Paragraph.text` (display text) unchanged; rule words are normalized with `normalize()` before matching; whole-word by default using `(?<!\w)` and `(?!\w)` (not `\b`, so punctuation words like `C++` and `Dr.` work and boundaries are Unicode-aware); case-insensitive by default via per-alternative `(?i:...)`; one left-to-right pass, longest match first, ties broken by rule order (earlier rule wins), no rescanning (no cascades); replacement text inserted verbatim (no case transfer); each rule shows its match count; `LexiconRule.word` rejects empty or whitespace-only words. **Known limit:** `\w` includes CJK characters, so a `whole_word=true` rule never matches inside a CJK run (`whole_word=false` is needed for CJK rules). *Rationale: lets users fix mispronounced names predictably without touching the book text.*
3. **Number and abbreviation normalization is left to each model**; an adapter may declare that its model needs pre-normalization, and then the adapter does it with the model's own recommended tool. *Rationale: most models handle this themselves, and we must not reimplement model text processing.*
4. **Sentence splitting:** pipeline order is (1) dialogue spans for the whole paragraph, (2) sentence splitting within each span, (3) greedy packing within each span. Language is the lowercased primary subtag of `Book.language` (`"en-US"` → `"en"`; `None` → `"en"`). Use `pysbd` (`clean=False`, one cached `Segmenter` per language) when supported; otherwise (and on span-reproduction mismatch, logging a warning) use the punctuation fallback splitting after `[.!?…。！？؟।]+` plus trailing closing quotes/brackets followed by whitespace or end of text (CJK terminators `。！？` need no trailing whitespace). `"\n"` is always a sentence boundary. *Rationale: a proven splitter where one exists, a simple fallback elsewhere, and line breaks always mark boundaries.*
5. **Chunking:** whole sentences from each span are greedily packed up to the checkpoint's `max_chars`; chunks never cross a role span or paragraph boundary (a voice change always starts a new chunk); chunk texts are stripped. A sentence longer than `max_chars` is split at `;` / `；`, then `:` / `：`, then `,` / `，` / `、` (keeping trailing closing quotes/brackets with the delimiter), then spaces, splitting at the rightmost delimiter keeping left `<= max_chars` and recursing on the rest; last resort is a hard split at `max_chars` never placed directly before a Unicode combining mark (`unicodedata.combining`). IDs: `Sentence.id = "s_" + sha256(f"{paragraph_id}\0{index}\0{text}")[:16]` and `Chunk.id = "c_" + sha256(f"{paragraph_id}\0{index}\0{text}")[:16]`. *Rationale: natural prosody within each model's input limit, and clean pauses at voice changes and paragraph ends.*
6. **Dialogue detection:** text inside paired quotation marks (`“…”`, `"…"` alternating open/close, `«…»`, `「…」` everywhere; `„…“` for `de`, `cs`, `sk`, `pl`, `bg`, `ro`, `hu` where `“` closes instead of opening), including the quote marks, when the content has at least 2 whitespace-delimited words (or at least 2 non-punctuation characters when it has no whitespace in CJK). An opening quote left unclosed at paragraph end with every earlier quote balanced is treated as continued speech (dialogue to paragraph end, not flagged); any other imbalance (stray closer, unclosed opener in the middle, mismatched pairs) makes the whole paragraph narration with `unbalanced_quotes=True`. **Known limit:** British single-quote `‘…’` dialogue is not detected because it conflicts with apostrophes and is read by the narrator voice. *Rationale: enables a separate dialogue voice and multi-paragraph speeches while avoiding wrong guesses on ambiguous text.*

## C1.3 Synthesis

- **Seed:** each project gets a random base seed at creation (recorded); chunk seed = hash(base seed, chunk id); tests always fix the base seed. *Rationale: renders are reproducible and a chunk can be re-rolled independently.*
- **Device:** the best available tier for the checkpoint (CUDA if supported and it fits, else CPU); the user can force CPU. *Rationale: fastest option that works, with an override.*
- **dtype:** `auto` (SPEC B6). *Rationale: each adapter knows its model's safe precision.*
- **CPU threads:** all physical cores (Settings can lower it). *Rationale: fastest default; the user can leave headroom.*
- **Speed:** 1.0 (range 0.5–2.0, only for adapters that support it). *Rationale: the model's natural pace; the range is what models handle without artifacts.*

## C1.4 Per-chunk quality checks (in the app)

| Check | Default | On failure | Rationale |
|---|---|---|---|
| Duration vs expected (expected = characters ÷ the voice's measured characters per second, calibrated from its preview) | ratio within **0.5–2.0** | Retry once with a new seed; still failing → "needs review". | Catches truncated or runaway generations without flagging normal pacing variation. |
| Internal silence | no silence **longer than 2.0 s** (below −50 dBFS) | Same. | Long dead air inside a chunk is a typical model failure. |
| Clipping | **under 0.1 %** of samples at full scale | Same. | Audible distortion shows up well before it becomes common. |
| Empty or NaN audio | none | Same. | Always a failed generation. |

## C1.5 Assembly and export

- **Pauses:** 250 ms between chunks within a paragraph, 600 ms between paragraphs, 1,500 ms after a chapter title, 2,000 ms at the end of a chapter. *Rationale: natural narration rhythm that makes structure audible.*
- **Resampling:** all chunks to **44.1 kHz mono** (ffmpeg's `soxr` resampler if the LGPL build includes it, else ffmpeg's default; T05.6 checks). *Rationale: one common format for mixing models with different native rates; mono suits speech.*
- **Loudness:** two-pass EBU R128 `loudnorm` per chapter to **−18 LUFS integrated, −3 dBTP true peak**. *Rationale: inside the common audiobook guideline of −23 to −18 dB RMS with peaks at −3 dB.*
- **M4B:** AAC-LC **64 kbit/s mono**, chapter markers from included chapters, cover art, title/author/album tags, narrator tag = voice name(s), comment = "AI-narrated with <model> (<license>)", plus "Personal use only" when any non-commercial model was used. *Rationale: small files with good speech quality, proper chapters, and honest license labelling.*
- **MP3 per chapter:** 96 kbit/s mono, ID3 tags as above. *Rationale: a compatible fallback for players without M4B support.*
- **`render.json`** records: render id, timestamps, app/core/adapter/worker/pack versions, uv and Python versions, OS, hardware summary, book hash and per-chapter text hashes, lexicon hash, voices (frozen), model ids/checkpoints/revisions with file hashes, all parameters, base seed, QC summary, ffmpeg version and exact command lines. *Rationale: any render can be reproduced and audited.*
